独立台账口径，包含未同意 analytics 的真实订单；按创建 cohort 统计并观察7/14/30日成熟度。询盘须真实收到，WhatsApp或表单按钮点击不计询盘。

判断依据

流量少且各阶段比例正常 → 优先增加合适流量。套餐浏览足够而预约点击低 → 检查价格、作品、交付和信任信息。点击后不开始 → 检查入口、跨域与加载。开始后不提交 → 检查可预约日期、表单和照片上传。提交后不确认 → 检查PayNow操作和订金确认时延。

拒绝同意、拦截器、跨设备和WhatsApp聊天会造成缺失。小样本与未成熟订单只能提示调查方向，不能证明套餐有问题。
